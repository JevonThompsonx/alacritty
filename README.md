# Alacritty Config — JevonThompsonx

Catppuccin Mocha-themed Alacritty terminal config.

## Files
- `alacritty.toml` — Main config. Inline color scheme (no theme import required).

## Theme
- Background: `#1E1E2E` (Catppuccin Mocha base)
- Foreground: `#CDD6F4`
- Cursor: `#F5E0DC` (rosewater)
- All 16 ANSI colors from Catppuccin Mocha palette

## Font
- JetBrainsMono Nerd Font, size 15

## Install
```bash
cp alacritty.toml ~/.config/alacritty/alacritty.toml
```
